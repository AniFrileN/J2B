# Бот закупок

Telegram-бот для общепита. Повара и бармены пишут в общую группу, что нужно купить. Управляющий пишет `/itog` и получает Excel-таблицу, где все позиции уже разложены по поставщикам. Для каждой позиции бот выбирает поставщика с самой низкой ценой.

Списки и прайсы разбирает ИИ, поэтому писать можно как угодно: «молоко 10 л», «лимонов кило 3», «сливки 33 пару штук». На выбор два ИИ: бесплатный Gemini от Google или платный, но дешёвый Claude от Anthropic. Переключаются одной строкой в настройках.

## Как это работает

1. **Прайсы.** Управляющий в личке с ботом пишет `/price Метро` и присылает прайс: Excel (.xlsx/.xls), CSV, PDF, фото или просто текст. Можно несколько файлов подряд, в конце `/done`. Новый прайс заменяет старый у этого поставщика.
2. **Списки.** Бот добавлен в рабочую группу и молча запоминает все сообщения.
3. **Заказ.** Управляющий пишет в группе `/itog`. Бот раскладывает всё по поставщикам, присылает короткую сводку с суммами и предлагает кнопками выбрать, в каком виде прислать заказ:
   - **📊 Excel-таблица:** лист «Сводка» со всеми поставщиками и суммами, отдельный лист на каждого поставщика и лист «Не найдено»;
   - **💬 Одним сообщением:** весь заказ текстом в чат;
   - **📨 По поставщикам:** отдельное сообщение на каждого поставщика, чтобы его удобно было переслать.

   Кнопки можно нажимать сколько угодно раз, ИИ при этом заново не вызывается. Готовые заказы хранятся 60 дней. После `/itog` собранные списки обнуляются, и бот начинает собирать заново.

Если позицию никто из поставщиков не продаёт, она попадает в «Не найдено». В сводке также видно, сколько эта же позиция стоит у других поставщиков.

## Несколько точек

Добавьте бота в чат каждой точки. Каждый чат копит свои списки отдельно, а `/itog` в чате точки собирает заказ только этой точки. В заголовке заказа и в имени Excel-файла стоит название чата. Прайсы общие на все точки: загружаете один раз, и они работают везде. `ADMIN_IDS` тоже действует во всех чатах.

## Команды

| Команда | Что делает |
|---|---|
| `/itog` | Собрать заказ из всех списков и обнулить их |
| `/list` | Показать, что бот уже собрал в этом чате |
| `/clear` | Удалить собранные списки без заказа |
| `/price Поставщик` | Загрузить прайс (в личке с ботом) |
| `/done` | Закончить загрузку прайса |
| `/prices` | Какие прайсы загружены |
| `/find слово` | Найти позицию в прайсах: как записана, единица, цена |
| `/delprice Поставщик` | Удалить прайс |
| `/start`, `/help` | Подсказка и ваш Telegram ID |

## Установка (один раз)

1. **Создайте бота.** В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните токен.
   Затем там же: `/setprivacy` → выберите бота → **Disable**. Без этого бот не видит обычные сообщения в группе.
2. **Получите ключ ИИ** (подробнее в разделе «Какой ИИ выбрать» ниже):
   - **Gemini (бесплатно):** откройте [aistudio.google.com](https://aistudio.google.com), войдите через Google-аккаунт и нажмите **Get API key**. Карта не нужна.
   - **Claude (платно):** [console.anthropic.com](https://console.anthropic.com) → API Keys, затем пополните баланс.
3. **Установите Python 3.10 или новее** с [python.org](https://www.python.org/downloads/). При установке на Windows отметьте галочку **Add Python to PATH**.
4. **Скачайте проект** (на GitHub: Code → Download ZIP) и распакуйте.
5. Скопируйте файл `.env.example` в `.env` и впишите `BOT_TOKEN` и ключ ИИ: `GEMINI_API_KEY` или `ANTHROPIC_API_KEY`. Для Claude также поменяйте строку `AI=gemini` на `AI=claude`.
6. **Запустите:** на Windows дважды кликните `run.bat`, на Ubuntu смотрите раздел «Ubuntu» ниже. Первый запуск ставит зависимости, это займёт минуту.
7. Напишите боту `/start` в личке. Он покажет ваш Telegram ID. Впишите его в `ADMIN_IDS` в `.env` и перезапустите бота. Теперь только вы можете загружать прайсы и делать `/itog`. Несколько ID пишите через запятую.
8. Добавьте бота в рабочую группу. Если бот уже был в группе до шага с `/setprivacy`, удалите его и добавьте заново.

Бот работает, пока открыто окно `run.bat` и включён компьютер. Чтобы он работал круглосуточно, его можно перенести на недорогой сервер (VPS).

## Установка на сервер (VPS) одной командой

Подходит для сервера на Ubuntu или Debian, где уже работает сайт. Бот ставится рядом и сайт не трогает: работает под отдельным пользователем `zakupbot`, ему не нужны домен и порты, а память ограничена 900 МБ. Обычно он занимает около 200 МБ, при чтении большого PDF до 350–400 МБ.

Подключитесь к серверу по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/AniFrileN/J2B/ccr-a061dd1d-xro167/install.sh | sudo bash
```

Скрипт спросит токен бота, выбор ИИ и ключ. Пока вы их вводите, символы на экране не видны, это нормально. Дальше скрипт сам поставит всё нужное, включит автозапуск и проверит, что бот работает. Бот ставится в `/opt/zakup-bot`.

Чтобы обновить бота, запустите ту же команду ещё раз. Настройки и база при этом сохраняются.

Важно: сервер должен быть не в России. Gemini и Claude с российских IP не работают, и скрипт предупредит об этом.

## Ubuntu (домашний ПК)

```bash
sudo apt update && sudo apt install -y git python3-venv
git clone -b ccr-a061dd1d-xro167 https://github.com/AniFrileN/J2B.git ~/zakup-bot
cd ~/zakup-bot
cp .env.example .env
nano .env        # впишите токен и ключ, сохраните: Ctrl+O, Enter, Ctrl+X
./run.sh         # запуск в окне терминала, остановка — Ctrl+C
```

### Ubuntu: автозапуск

Чтобы бот работал в фоне, сам запускался после перезагрузки и перезапускался при сбоях:

```bash
mkdir -p ~/.config/systemd/user
cp ~/zakup-bot/zakup-bot.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now zakup-bot
sudo loginctl enable-linger $USER   # работать, даже когда вы не вошли в систему
```

Полезные команды:
- `systemctl --user status zakup-bot` — работает ли бот;
- `journalctl --user -u zakup-bot -f` — смотреть, что он пишет (выход — Ctrl+C);
- `systemctl --user restart zakup-bot` — перезапуск после изменения `.env`;
- `cd ~/zakup-bot && git pull && systemctl --user restart zakup-bot` — обновить бота.

## Какой ИИ выбрать

| | Gemini (`AI=gemini`) | Claude (`AI=claude`) |
|---|---|---|
| Цена | бесплатно | около $0.5–1 в месяц на модели Claude Haiku 5.5 |
| Нужна карта | нет | да, пополнение от ~$5 |
| Ваши данные | на бесплатном тарифе Google использует их для улучшения своих продуктов | по умолчанию не используются для обучения |
| Лимиты | ограничено число запросов в минуту и в день (смотрите в AI Studio) | практически не ограничено |

Оба работают из Казахстана. Telegram в любом случае бесплатный.

**Совет:** начните с Gemini. Если вас смущает, что Google видит прайсы и цены поставщиков, или бот упирается в лимиты, поменяйте в `.env` строку на `AI=claude` и впишите `ANTHROPIC_API_KEY`.

Модели по умолчанию: `gemini-3.8-flash` и `claude-haiku-5-5`. Для более точного сопоставления можно поставить `CLAUDE_MODEL=claude-opus-5-5`: это умнее, но примерно в 40 раз дороже, порядка 10–50 центов за `/itog`.

Если упрётесь в бесплатный лимит Gemini, бот подождёт и повторит запрос, а если лимит на день кончился, скажет об этом. Собранные списки при этом не теряются.

Валюта по умолчанию — тенге (₸). Её можно поменять строкой `CURRENCY=₽` в `.env`.

## Ограничения

- Списки бот понимает только текстом. Фото рукописных списков и голосовые пока не читает.
- Word-файлы (.docx) с прайсами не поддерживаются: сохраните их в PDF или скопируйте текст.
- Цены бот берёт из последнего загруженного прайса, поэтому прайсы нужно обновлять.

## Для разработчика

```
zakup_bot/
  bot.py      — команды Telegram (aiogram 3)
  ai.py       — запросы к ИИ (Gemini или Claude): разбор прайсов и сопоставление списков
  files.py    — чтение Excel/CSV/PDF/фото
  planner.py  — выбор самого дешёвого поставщика, сложение одинаковых позиций
  excel.py    — итоговая таблица
  db.py       — SQLite: прайсы и собранные сообщения
tests/        — pytest
```

Запуск тестов: `pip install -r requirements.txt pytest && python -m pytest`.
